# Acervo de referências (nível 7)

Tudo que ficou bom vai para cá. A skill `carrossel-animado` lê esta pasta
antes de criar um carrossel novo e procura o que os aprovados têm em comum
(ritmo, paleta, tipo de gancho, densidade de texto, sons) para repetir o
estilo mesmo quando o pedido for curto.

## Como registrar

Crie `referencias/<slug>.md` com:

```markdown
# <título do carrossel>
- pasta: carrossel/<slug>/ (ou link do post publicado)
- tema / público:
- gancho que funcionou:
- estrutura: n slides — capa, …, CTA
- ritmo: 6 s · 120 BPM · música cinematic
- o que eu mais gostei: (2–3 pontos concretos: "contador com ticker", "marcador lima no título")
- o que evitar da próxima vez:
```

Se tiver referências externas (prints de carrosséis de outras pessoas),
salve a imagem aqui com um `.md` do mesmo nome dizendo **o que** gostou.
